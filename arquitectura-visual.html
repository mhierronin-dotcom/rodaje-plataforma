🏠 Dashboard de Proyectos

Punto de entrada principal a la plataforma. Vista centralizada de todos los rodajes con control visual del estado.

Funcionalidades Principales

📊 Vista General de Rodajes

Cards visuales por proyecto mostrando: cliente, director, presupuesto, progreso, estado, fechas clave.

🔍 Filtros Avanzados

Filtrar por estado (Activos, Cerrados, Archivo), cliente, fecha, director, búsqueda por nombre.

⚡ Acciones Rápidas

Crear nuevo rodaje, editar, marcar como cerrado/archivado, ver detalles, duplicar proyecto.

📈 Información Resumida

En cada card: cliente, director, presupuesto total/gastado con barra de progreso visual, fechas de producción.

Estados de Proyecto

🟢
Activo - Proyecto en desarrollo o en producción
🔵
Cerrado - Proyecto finalizado, en post-producción
🟡
Archivo - Proyecto completado, archivado para referencia

📅 Planificación - Plan de Rodaje

El corazón de la plataforma. Plan interactivo y visual por día, inspirado en shooting plans profesionales reales.

Estructura Principal

📆 Organización por Día

Cada día de rodaje se divide en sets/locaciones con múltiples escenas agrupadas con horarios y duraciones.

🎬 Escenas Detalladas

Cada escena incluye: número, nombre, descripción de guión, horarios (inicio/fin), duración, cast asignado.

🔗 Relaciones Entre Módulos

Cómo los diferentes apartados se conectan y trabajan juntos de forma inteligente.

Flujo de Relaciones

DASHBOARD (Home) ├─ Seleccionar Proyecto │ └─ PROYECTO ESPECÍFICO ├─ 📅 PLANIFICACIÓN │ ├─ Define escenas por día │ ├─ Establece horarios y tiempos │ ├─ Agrupa locaciones/sets │ └─ Asigna CAST y EQUIPO por escena │ ├─ 👥 CASTING │ ├─ Fichas de actores/modelos │ ├─ Fotos y perfiles │ └─ Se asignan a escenas en PLANIFICACIÓN │ ├─ 🎨 ESTILISMO │ ├─ Vestuario por escena │ ├─ Maquillaje y accesorios │ └─ Se asigna a CAST en PLANIFICACIÓN │ ├─ 💼 EQUIPO │ ├─ Directorio de personas │ ├─ Contacto y documentación │ └─ Se asignan a SETS/escenas en PLANIFICACIÓN │ └─ 💰 PRESUPUESTO ├─ Suma costos de EQUIPO (tarifa × días) ├─ Suma costos de CASTING (tarifa × días) ├─ Suma costos de ESTILISMO (proveedores) └─ Control global financiero

Flujos de Datos Principales

Planificación → Casting

Las escenas definidas en planificación asignan actores del módulo de casting.

Planificación → Estilismo

Cada escena asignada a un actor trae consigo el look estilístico definido para ese personaje en esa escena.

Planificación → Equipo

Las escenas y sets requieren departamentos específicos (cámara, iluminación, etc) que se asignan del equipo disponible.

Todos → Presupuesto

Casting (tarifa/día × días), Equipo (tarifa/día × días), Estilismo (costos proveedores) se suman automáticamente.
