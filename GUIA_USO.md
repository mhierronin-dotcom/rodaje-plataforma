# 🎬 Plataforma Rodaje Studio - Guía de Uso

## Introducción

**Rodaje Studio** es una plataforma integral de gestión de producciones audiovisuales diseñada para productoras, agencias y estudios. Permite organizar, visualizar y compartir toda la información relativa a un rodaje de forma clara, estructurada y profesional.

---

## 📋 Características Principales

### ✅ Para Productoras/Agencias (Rol Admin)
- Crear y gestionar múltiples rodajes
- Acceso completo a todas las secciones
- Control de presupuesto y desglose de costos
- Planificación de cronograma y locaciones
- Gestión de casting y elenco
- Definición de estilismo (vestuario, maquillaje, accesorios)
- Tratamiento visual y paleta de colores
- Vista completa para presentación interna

### 👁️ Para Clientes (Rol Cliente)
- Visualización de rodajes asignados
- Acceso limitado a secciones permitidas
- Casting, estilismo y tratamiento visual
- Dashboard con estado del proyecto
- No acceso a información financiera
- Interfaz simplificada y enfocada

---

## 🚀 Cómo Empezar

### Paso 1: Seleccionar tu Rol

Al iniciar, verás dos opciones:

```
👤 Acceso Productora/Agencia
👁️ Acceso Cliente
```

**Productora**: Acceso total a la plataforma
**Cliente**: Vista limitada con información del rodaje

### Paso 2: Navegar por Rodajes

En la **barra lateral izquierda** verás:
- Lista de tus rodajes activos
- Botón "+ Nuevo Rodaje" (solo para admin)
- Click en cualquier rodaje para cambiar de proyecto

### Paso 3: Explorar Secciones

Una vez dentro de un rodaje, usa las **tabs de navegación** para acceder a:

| Sección | Admin | Cliente | Descripción |
|---------|-------|---------|-------------|
| 📊 Dashboard | ✓ | ✓ | Resumen general del rodaje |
| 📅 Planificación | ✓ | ✗ | Cronograma y locaciones |
| 👥 Casting | ✓ | ✓ | Elenco y perfiles |
| 👗 Estilismo | ✓ | ✓ | Vestuario, maquillaje, accesorios |
| 💰 Presupuesto | ✓ | ✗ | Control financiero |
| 🎨 Visualización | ✓ | ✓ | Paleta de colores y referencias |

## 📊 Secciones Detalladas

### Dashboard
El punto de partida para cualquier rodaje. Muestra:
- **Estado del rodaje**: Planeación, En producción, Finalizado
- **Cronograma**: Fechas de inicio y fin, duración total
- **Presupuesto**: Gasto actual vs. presupuesto total (con barra de progreso)
- **Director y Locación**: Información de contacto principal

**Consejo**: Usa el dashboard para verificar el estado de un vistazo antes de entrar en detalles.

### Planificación (Solo Admin)
Organiza el timeline y locaciones del rodaje:

#### Timeline de Rodaje
- Listado por días de producción
- Actividades programadas para cada día
- Fácil identificación visual con números

#### Locaciones
- Todas las locaciones del shoot
- Útil para coordinar transporte y equipo
- Referencia rápida para el equipo

**Uso típico**: 
1. Definir duración total del rodaje
2. Asignar actividades por día (pre-producción, rodaje, post)
3. Listar todas las locaciones a visitar

### Casting
Gestión y visualización del elenco:

**Información por actor:**
- Nombre del personaje/rol
- Rango de edad
- Nacionalidad/características
- Estado (Confirmado, En audición, Rechazado)

**Para Admin**: 
- Agregar actores
- Actualizar estado de confirmaciones
- Gestionar disponibilidades

**Para Cliente**:
- Ver quién está en el proyecto
- Conocer características del elenco
- Estar informado de confirmaciones

### Estilismo
Define el look visual de la producción en 3 categorías:

#### 👗 Vestuario
- Atuendos para cada escena/personaje
- Referencias de estilo
- Cantidad de cambios

#### 💄 Maquillaje
- Estilos de maquillaje (natural, artístico, etc.)
- Productos recomendados
- Cambios por escena

#### ✨ Accesorios
- Props y accesorios por personaje
- Detalles de vestuario
- Elementos especiales (lentes, sombreros, etc.)

**Consejo**: La coherencia visual es clave. Usa esta sección para asegurar que todo el elenco tenga el look correcto.

### Presupuesto (Solo Admin)
Control financiero completo del rodaje:

#### Desglose por Categorías
- **Talento**: Caché de actores y extras
- **Equipo Técnico**: Cámaras, iluminación, sonido
- **Locaciones**: Renta de espacios
- **Post-producción**: Edición, color, sonido
- **Otros**: Catering, transporte, permisos

#### Visualización
- Barras de progreso para cada categoría
- Porcentaje del presupuesto total
- Gráfico de pastel para distribución visual

#### Control Total
- Presupuesto total
- Gasto actual
- Diferencia (sobrante o déficit)
- Alerta visual si se supera presupuesto

**Importante**: Revisa regularmente para mantener control de costos.

### Visualización
Define el lenguaje visual y estético del rodaje:

#### 🎨 Paleta de Colores
- Hasta 4 colores principais
- Se muestran en grandes muestras
- Código hex para referencia exacta
- Útil para maquillaje, vestuario, set design

#### Tratamiento Visual
- **Mood Board**: Descripción del vibe general (ej: "Energético, dinámico, urbano")
- **Referencias**: Links o nombres de películas/anuncios con estilo similar
- Crea coherencia visual en toda la producción

**Uso típico**:
1. Establecer mood board (conversa con el cliente)
2. Recopilar referencias visuales
3. Seleccionar paleta de colores
4. Comunicar a todos los departamentos

## 👥 Gestión de Rodajes

### Crear un Nuevo Rodaje

**Solo disponible para Admin**

1. Click en "+ Nuevo Rodaje" (sidebar izquierdo)
2. Completa:
   - **Nombre del rodaje**: Ej: "Campaña Nike 2026"
   - **Cliente**: Ej: "Nike Inc."
3. Click "Crear"

El rodaje se crea con valores por defecto y puedes empezar a completar información.

### Cambiar de Rodaje

1. Haz click en cualquier rodaje en el sidebar
2. Se abre automáticamente el dashboard de ese proyecto
3. Toda la navegación cambia al nuevo rodaje

### Estados Disponibles

- 🟡 **Planeación**: Proyecto en desarrollo inicial
- 🟢 **En producción**: Rodaje activo
- ⚫ **Finalizado**: Proyecto completado
- 🔴 **En post-producción**: Edición y finalización

## 🔐 Diferencias Entre Roles

### Admin (Productora/Agencia)

**Permisos:**
✓ Ver todas las secciones
✓ Crear rodajes
✓ Editar información completa
✓ Acceso al presupuesto
✓ Planificación detallada
✓ Crear usuarios clientes

**No puede:**
✗ Borrar rodajes (protección de datos)
✗ Acceso a datos de otros clientes (si hay múltiples)

### Cliente

**Permisos:**
✓ Ver dashboard del rodaje
✓ Ver casting y elenco
✓ Ver estilismo
✓ Ver tratamiento visual
✓ Ver paleta de colores

**No puede:**
✗ Ver presupuesto
✗ Ver planificación (fechas internas)
✗ Editar ninguna información
✗ Crear rodajes
✗ Acceso a otros rodajes

## 💡 Mejores Prácticas

### Para Productoras

1. **Mantener actualizado**: Revisa presupuesto semanalmente
2. **Comunicar cambios**: Si hay cambios en casting o cronograma, notifica al cliente
3. **Validar referencias**: Asegúrate de que cliente aprueba visualización antes de producción
4. **Completar datos**: Llena toda la información posible en planificación
5. **Compartir links**: Usa la URL para compartir rodajes específicos con clientes

### Para Clientes

1. **Revisar regularmente**: Mantente informado del progreso
2. **Dar feedback temprano**: Especialmente en casting y estilismo
3. **Confirmar visualización**: Aprueba paleta y references cuanto antes
4. **Comunicar cambios**: Si hay ajustes, notifica al equipo
5. **No editar datos**: Comunicar cambios por otro canal

## 🎯 Casos de Uso Típicos

### Caso 1: Nuevo Rodaje Comercial

```
1. Admin crea rodaje "Comercial Coca-Cola"
2. Completa planificación: 10 días, 3 locaciones
3. Agrega casting: 2 actores principales
4. Define estilismo: Vestuario casual, maquillaje natural
5. Establece paleta: Rojos, dorados, blancos
6. Comparte con cliente para aprobación
7. Cliente revisa y da feedback
8. Admin ajusta según comentarios
9. Inicia producción
```

### Caso 2: Seguimiento Presupuestario

```
1. Admin abre presupuesto
2. Ve que se gastó 95K de 150K (63%)
3. Nota que Talento está en rojo (80% del presupuesto)
4. Analiza desglose
5. Toma decisiones para controlar costos
6. Monitorea semanalmente
```

### Caso 3: Presentación al Cliente

```
1. Admin entra como "Productora"
2. Ve todas las secciones
3. Prepara presentación con casting, estilismo, visualización
4. Comparte URL con cliente en acceso "Cliente"
5. Cliente entra y ve información permitida
6. Dejan feedback en cada sección
7. Admin implementa cambios
```

## 🚨 Troubleshooting

### Problema: No veo presupuesto
**Solución**: Presupuesto solo está disponible para Admin. Si eres Cliente, contacta a la productora.

### Problema: No puedo editar información
**Solución**: El acceso Cliente es solo lectura. Si necesitas hacer cambios, avisa a la productora.

### Problema: El rodaje no aparece en mi lista
**Solución**: 
- Si eres Admin, crea un nuevo rodaje
- Si eres Cliente, solicita al admin que te asigne el rodaje

### Problema: Datos no se guardan
**Solución**: En esta versión demo, los datos se guardan en sesión. Actualiza la página para conservar los cambios.
